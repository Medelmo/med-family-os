## Design verification checklist

- no clipped text
- no overlapping layers
- all interactive targets have visible states
- mobile navigation is usable with one hand
- focus ring is visible
- status is never color-only
- dialogs have correct focus order
- empty/error/loading states match component system
- table becomes card/list on mobile
- dense timeline remains readable
- contrast meets WCAG 2.2 AA
